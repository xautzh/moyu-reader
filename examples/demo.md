这是一份用于验证 **墨阅 v2** 的示例文档。它覆盖常见 Markdown 内容、中文排版、本地图片、公式、图表和链接。

![阅读流程](./assets/reading-flow.svg)

## 阅读体验

墨阅专注于本地 Markdown 写作与阅读，支持所见即所得、源码、分屏和预览四种模式，也支持浅色、深色和跟随系统三种主题。

> 好的阅读工具不应抢走注意力，而应让结构、节奏和文字自然显现。

### 常用快捷键

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 打开文件 | `Ctrl + O` | 选择本地 Markdown 文档 |
| 保存文件 | `Ctrl + S` | 保存当前编辑内容 |
| 文档查找 | `Ctrl + F` | 搜索当前渲染内容 |
| 切换侧栏 | `Ctrl + Shift + B` | 显示或隐藏目录与最近文件 |
| 切换模式 | `Ctrl + 1 / 2 / 3 / 4` | 所见即所得、源码、分屏、预览 |
| 调整字号 | `Ctrl + + / -` | 放大或缩小正文 |
| 重置字号 | `Ctrl + 0` | 恢复为 100% |
