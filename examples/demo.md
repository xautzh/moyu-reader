## 阅读体验

墨阅专注于本地 Markdown 阅读，支持浅色、深色和跟随系统三种主题。你可以使用工具栏调整字号，也可以使用 `Ctrl` + `+` / `-` 快速缩放正文。

> 好的阅读工具不应抢走注意力，而应让结构、节奏和文字自然显现。

### 常用快捷键

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 打开文件 | `Ctrl + O` | 选择本地 Markdown 文档 |
| 文档查找 | `Ctrl + F` | 搜索当前渲染内容 |
| 切换侧栏 | `Ctrl + B` | 显示或隐藏目录与最近文件 |
| 调整字号 | `Ctrl + + / -` | 放大或缩小正文 |
| 重置字号 | `Ctrl + 0` | 恢复为 100% |
