# 墨阅 v2.0.0 本地验收清单

无需安装即可验证。请在项目目录 `D:\self\moyu-reader` 执行：

```powershell
npm install
npm run build
npm start
```

## 1. 基础编辑与保存

1. 打开 `examples/demo.md`，确认默认进入“所见即所得”。
2. 在正文末尾输入一段文字，标题栏应出现未保存圆点，底部显示“未保存”。
3. 按 `Ctrl + S` 保存，圆点消失，磁盘文件可看到新内容。
4. 切换到“源码”，修改 Markdown；再切换“预览”，内容应立即同步。
5. 切换“分屏”，左侧源码和右侧预览应同时可编辑/刷新。

建议先复制 `examples/demo.md` 后再手工修改，避免改动仓库示例。

## 2. 数据安全

1. 修改内容但不保存，然后关闭窗口，应出现保存 / 不保存 / 取消对话框。
2. 修改后等待约 1 秒，强制结束应用并重新打开同一文件，应提示恢复草稿。
3. 保持墨阅中存在未保存内容，再用记事本修改同一文件，应出现磁盘冲突提示。
4. 分别验证“继续编辑”“重新载入”“覆盖磁盘”，确认没有静默覆盖。
5. 开启自动保存，停止输入约 2 秒后，应自动保存已存在于磁盘的文档。

## 3. 扩展内容

1. 插入本地图片，确认图片被复制到文档同级 `assets` 目录，Markdown 使用相对路径。
2. 输入 `$E = mc^2$` 和 `$$...$$`，预览中应由 KaTeX 渲染。
3. 输入 Mermaid 代码块，预览中应显示图表；错误语法应显示错误提示而非导致白屏。
4. 验证表格、任务列表、链接、代码块和图片在四种模式间切换后仍保留。
5. 打开带 `---` YAML Front Matter 的文档，所见即所得模式应显示“已安全保留”提示；编辑正文并保存后，元数据定界符、缩进和内容应保持不变。

## 4. 工作区与导出

1. 在侧栏“文件”页打开一个文件夹，确认只列出 Markdown 文档并可切换。
2. 验证大纲随标题编辑实时更新。
3. 导出 HTML，确认正文、样式、公式和相对图片路径可用。
4. 导出 PDF 并执行系统打印，确认只输出文档正文，不包含应用工具栏。

## 5. 自动化回归

```powershell
npm run lint
npm run build
npm run qa:electron
```

成功时 `qa:electron` 输出 `"status": "passed"`，截图位于 `output/playwright/qa-*`。
