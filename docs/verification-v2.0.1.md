# v2.0.1 更新功能验收

## 桥接安装

1. 在已安装 `v1.0.0` 或 `v2.0.0` 的 Windows 环境中运行 `Moyu-2.0.1-Windows.exe`。
2. 确认安装程序可以覆盖升级，原有文档不受影响。
3. 启动墨阅，在“帮助”菜单确认显示“检查更新…”和当前版本 `2.0.1`。

## 更新入口

1. 点击“帮助 → 检查更新…”。
2. 当前已是最新版时，应显示“已是最新版本”。
3. 网络失败时，应显示可重试的错误状态，编辑和保存功能不受影响。

## 后续版本自动更新

发布高于 `v2.0.1` 的正式 Release 后：

1. `v2.0.1` 应提示发现新版本。
2. 点击下载后应显示进度，并在完成后提供“立即重启并安装”。
3. 有未保存内容时，应先出现保存确认；取消关闭不会安装更新。
4. 重启后应进入新版本，文档和用户设置保持不变。

> macOS 当前构建未签名，自动更新功能会明确显示暂不支持，仍通过 Release 手动下载更新。
